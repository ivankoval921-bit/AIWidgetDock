• Блок каждого ИИ теперь из двух частей с вертикальной перегородкой: слева лимиты (5 часов и неделя), справа текущий чат: сверху токены, снизу обратный отсчёт кэша. Старый вид (чат третьей строкой) остался в конструкторе: «Стандарт: чат третьей строкой».
• Кэш и токены показываются и для чатов Claude Code и Cowork: время последнего хода берётся из журнала.
• Окно подробностей больше не мигает и не дёргается: оно обновляется, только когда изменились цифры.
• Двойной клик по блоку ИИ открывает подробности (раньше сразу закрывал). Закрыть: ещё один клик или двойной клик по самому окну.
• Конструктор вида: 17 готовых наборов, формы (столбик, полоса, квадрат), пять тем, переключатели каждого элемента. Откат версии и безопасная установка (прежняя версия возвращается, если новая не запустилась). Antigravity пропадает из блока, когда его окно закрыто.
