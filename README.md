# AIWidgetDock

Маленький виджет лимитов ИИ для Windows: **Claude, Codex, Antigravity, Grok** в одном блоке.

- Для каждого запущенного ИИ — две строки: **5-часовой лимит** (процент и сколько осталось до сброса) и **недельный лимит** (процент, дата и час сброса).
- Строка появляется, когда программа ИИ запущена, и пропадает, когда закрыта.
- Цвет по шкале израсходованного: зелёный 0–20%, синий 20–40%, жёлтый 40–60%, оранжевый 60–80%, красный 80–100%.
- Клик по строке — подробности (сессия, неделя, окно контекста, где программа его отдаёт).
- Правый клик — настройки: шрифт, жирность, курсив, ПРОПИСНЫЕ, размер, масштаб, фон (чёрный / полупрозрачный / без фона).
- Обновление в один клик: меню → «Проверить обновление».

## Установка
1. Скачайте **AIWidgetDock.exe** из раздела [Releases](../../releases/latest).
2. Положите в любую папку и запустите. Чтобы стартовал с Windows: правый клик по виджету → «Запускать с Windows».

## Подключение аккаунтов
- **Claude** — войдите в Claude Desktop (или на claude.ai в Chrome / Firefox).
- **Codex** — войдите в приложение Codex и сделайте хотя бы один запрос.
- **Antigravity** — откройте Antigravity и войдите в аккаунт Google.
- **Grok** — точных лимитов нет, показывается примерный расход «~».

Настройки и статистика расчётов: `%APPDATA%\AIWidgetDock`.
