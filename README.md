
# AIWidgetDock

Маленький виджет лимитов ИИ для Windows: **Claude, Codex, Antigravity, Grok** в одном блоке.

- Для каждого запущенного ИИ — строки: **5-часовой лимит** (процент и сколько осталось до сброса), **недельный лимит** (процент, дата и час сброса) и, начиная с 1.1, **текущий чат**.
- Строка появляется, когда программа ИИ запущена, и пропадает, когда закрыта.
- Цвет лимитов по шкале израсходованного: зелёный 0–20%, синий 20–40%, жёлтый 40–60%, оранжевый 60–80%, красный 80–100%.
- Клик по строке — подробности (сессия, неделя, токены чата, кэш, окно контекста).
- Правый клик — настройки: шрифт, жирность, курсив, ПРОПИСНЫЕ, размер, масштаб, фон (чёрный / полупрозрачный / без фона), пределы чата, срок кэша, звук.
- Обновление в один клик: меню → «Проверить обновление».

## Строка «чат» (версия 1.1)
Пример: `кэш 54м  187k/400k`.

- **Кэш.** Пока вы пишете в чат с ИИ, он читает историю из дешёвой памяти (кэша). Каждый ход обновляет отсчёт. Если пауза длиннее срока кэша, следующий ход читает весь чат заново и стоит заметно дороже.
  Виджет показывает, сколько минут кэша осталось. Когда осталось меньше четверти срока, цифра краснеет и мигает. В последние минуты появляется «ХОД!», звучит сигнал и всплывает уведомление: сделайте любой ход в чате (хоть «подожди, думаю»).
  Срок кэша для Claude Code определяется автоматически (5 минут или 1 час), для Codex по умолчанию 10 минут. Его можно задать в настройках.
- **Токены чата.** Сколько токенов занято в текущем чате и какой предел. Четыре зоны: зелёная до 150k, жёлтая до 300k, оранжевая до 350k, красная выше (для предела 400k; для другого предела доли те же). В красной зоне цифра мигает: пора переходить в новый чат.
  Пределы по умолчанию: Claude 400k, Codex 400k, Antigravity 500k, Grok 400k. Меняются в настройках.
- **Откуда данные.** Claude Code и Codex считаются автоматически из их журналов на диске. У Antigravity и Grok токены обновляются движком или кнопкой «Обновить», кэш-таймера у них нет.

## Установка
1. Скачайте **AIWidgetDock.exe** из раздела [Releases](../../releases/latest).
2. Положите в любую папку и запустите. Чтобы стартовал с Windows: правый клик по виджету → «Запускать с Windows».

## Подключение аккаунтов
- **Claude** — войдите в Claude Desktop (или на claude.ai в Chrome / Firefox).
- **Codex** — войдите в приложение Codex и сделайте хотя бы один запрос.
- **Antigravity** — откройте Antigravity и войдите в аккаунт Google.
- **Grok** — точных лимитов нет, показывается примерный расход «~».

Настройки и статистика: `%APPDATA%\AIWidgetDock`.

## Сборка
`build.ps1` собирает один exe из `src\` (PyInstaller, Python 3.11).
